# Fake news detection

## Frontend

Avec [shadcn/ui](https://ui.shadcn.com) et [Vite](https://vite.dev/).

Pour démarrer le serveur, depuis `frontend/` : `npm run dev`.

Liste des composants : <https://ui.shadcn.com/docs/components>

## Backend

Avec [FastAPI](https://fastapi.tiangolo.com/).

Pour démarrer le serveur, depuis `backend/` : `uv run fastapi dev`.
